# Contributing to the IIMC Card Tool

Thank you for your interest in contributing to aviation safety! Because this tool is used for life-safety pre-flight planning, all contributions—whether bug reports, feature requests, or code—are taken very seriously.

## How to Contribute

### 1. Reporting Bugs
If you find a discrepancy in the Minimum Safe Altitude (MSA) calculations, or any other issue, please use the **Bug Report** issue template.
- Provide the exact coordinates or FAA Identifier you used.
- Provide the expected result versus the actual result.
- State which airspace or obstacle database cycle you are referencing.

### 2. Requesting Features
We welcome ideas from pilots and dispatchers. Please use the **Feature Request** issue template. Explain the operational use-case for your feature.

### 3. Submitting Code (Pull Requests)
1. Fork the repository.
2. Create a new branch for your feature or bugfix (`git checkout -b feature/your-feature-name`).
3. Ensure any mathematical changes to the MSA engine include justification and tests.
4. Commit your changes and push to your fork.
5. Open a Pull Request against our `main` branch.

All code will be carefully reviewed for accuracy before merging, as errors in this software can impact flight safety.
